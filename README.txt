سامانه‌ی کارفرما — راه‌اندازی

فایل‌های مخزن: server.js (سرور+دیتابیس) | karfarma.html (پنل کارفرما) | Dockerfile | README.txt
برنامه‌ی کارگر (index.html) به‌صورت APK جدا منتشر می‌شود و لازم نیست داخل مخزن باشد.

روش کار
- کارگر در برنامه ثبت‌نام می‌کند (نام + نام کاربری + رمز). هیچ تنظیم سروری ندارد.
- کارفرما در پنل (تب «کارگران») درخواست را تأیید یا رد می‌کند. بعد از تأیید، کارکردها خودکار ارسال می‌شود.
- اگر تأیید خودکار می‌خواهید: متغیر AUTO_APPROVE=1 (پیشنهاد نمی‌شود).
- فراموشی رمز کارگر: در پنل، فرم «افزودن / تغییر رمز» را با همان نام کاربری پر کنید.

اجرا روی کامپیوتر (Node 22.13 یا بالاتر، بدون نصب پکیج)
   ADMIN_PASS=رمزدلخواه node server.js
   پنل کارفرما: http://آدرس:3000/   (نام کاربری: admin)

استقرار رایگان فقط با گوشی (Render + Turso)
الف) turso.tech ← با حساب گیت‌هاب وارد شوید ← Database بسازید ← آدرس (شروع با libsql://) و یک Token بردارید.
ب) گیت‌هاب: مخزن خصوصی بسازید و چهار فایل بالا را آپلود کنید (در مرورگر گوشی «سایت دسکتاپ» را روشن کنید).
ج) render.com ← New ← Web Service ← مخزن ← Language: Docker ← Instance Type: Free.
د) Environment Variables:
   ADMIN_PASS   رمز کارفرما (خودتان انتخاب کنید؛ فقط بار اول ساخته می‌شود)
   TURSO_URL    آدرس libsql://...
   TURSO_TOKEN  توکن دیتابیس
   AUTO_APPROVE (اختیاری) مقدار 1 = تأیید خودکار ثبت‌نام‌ها
هـ) بعد از Deploy آدرس https://....onrender.com را باز کنید؛ با admin و ADMIN_PASS وارد شوید.
   همین آدرس را در index.html (متغیر SERVER) بگذارید و APK را دوباره بسازید.

فراموشی/تغییر رمز کارفرما
- با دانستن رمز فعلی: دکمه‌ی «تغییر رمز» بالای پنل.
- فراموشی: متغیر RESET_ADMIN_PASS=رمزجدید را در Environment بگذارید، سرویس را Restart کنید، وارد شوید و بعد متغیر را حذف کنید. داده‌ها پاک نمی‌شوند.

نکته: سرویس رایگان Render بعد از چند دقیقه بیکاری می‌خوابد و اولین درخواست حدود یک دقیقه طول می‌کشد. داده‌ها در Turso می‌مانند.
